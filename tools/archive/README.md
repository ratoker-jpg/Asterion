# Архив одноразовых инструментов

Скрипты прошлых PR и разовых исследований (аудит приоритета целей Nemexia, диагностика ботов, съёмки превью). Они не подключены к `package.json` и CI и не вызываются из игры. Лежат здесь на случай, если понадобится повторить исследование; пути внутри уже поправлены на `../../src`. Если скрипт не нужен — его можно удалить.
