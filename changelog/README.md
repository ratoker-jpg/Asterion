# Заметки для игрока

Экран «Что нового» в игре собирается из этой папки. Правила и формат: [docs/RELEASES.md](../docs/RELEASES.md), раздел «Заметки для игрока».

- `notes/` — один файл на PR, номер версии в нём не пишется.
- `images/` — картинки к заметкам (`.webp` или `.jpg`, до 200 КБ).

Проверить заметки: `node tools/changelog.mjs check`.

## «Весь роадмэп»

Вторая вкладка экрана «Что нового» показывает всю историю игры: главы, вехи, каждую правку с датой и раздел «Дальше». Текст лежит в `roadmap.json`, проверен вручную и входит в игру. С GitHub во время игры ничего не загружается, файл подгружается только при открытии вкладки.

**Правило владельца: файл обновляется раз в 150 PR, а не на каждый PR.** CI этого не требует и требовать не должен. В файле записаны последний вошедший PR (`lastPr`) и следующая граница (`refresh.nextAt`, сейчас **№300**).

Как обновить, когда подойдёт срок:

1. `node tools/roadmap.mjs pull raw.json` покажет, чего нет в файле и у чего сменился статус. Даты в нём по московскому времени, версия взята из тегов.
2. Для каждого нового PR написать запись: название и 1–3 предложения на языке игрока, решение владельца отдельным полем `decision`, если оно было. Ничего не придумывать: если описание скупое, смотреть, что реально изменилось.
3. Поднять `lastPr`, `updated`, `refresh.nextAt` (следующее кратное 150) и числа в `releases`, при необходимости добавить главу, вехи и освежить `plans`.
4. `node tools/roadmap.mjs check` и `node --test tools/roadmap.test.mjs`.

Что пишем и как:

- **Каждый номер от 1 до `lastPr`** есть в `prs` или в `excluded` с причиной. Сейчас исключён №3: это задача, а не правка.
- **Статусы.** `done` — вошло в игру. `closed` — закрыто без вливания: показывается как «не вошло в игру», с честной причиной, если она известна. `open` — «в работе».
- **Порядок** по дате, потом по номеру. Главы идут подряд и не перемешиваются.
- **Публичность.** Никаких адресов, ключей, путей, почты и служебных обсуждений, сервер называется просто «сервер». Названия других игр и служебные слова не пишем, проверка это ловит.
