# «Командование» — PR 1: доступ, союзы, заявки, состав

Реализует PR 1 из `ASTERION_COMMAND_PR_ROADMAP_V1`. Запросы ресурсов, заряды, миссия «Помощь союзу» (PR 2), журнал и финальная полировка (PR 3) сюда **не входят**.

## Контракт данных (для согласования перед PR 2)

`state.command` — `CommandState` версии 2 (`src/domain/command/types.ts`):

| Поле | Смысл |
|---|---|
| `alliances[]` | Реальные союзы: стабильный `id` (`alliance-N`, счётчик `nextSerial`, id не переиспользуются), название, тег, девиз, описание, знак, `leaderOwnerId`, `deputyOwnerId`, `leaderSince`, `members[]` |
| `alliances[].members[]` | `ownerId` (общий с вселенной/рейтингом/полётами), `displayName`, `joinedAt`, `lastActiveAt`, **`deliveredUnits`** (агрегат вклада: сумма фактически доставленных единиц всех четырёх ресурсов), `jointOperationCount`, `tieBreaker` (случайное число, один раз при вступлении, сохраняется) |
| `applications[]` | `pending / accepted / rejected / withdrawn / auto_rejected`, причина (`declined / full / already_member / disbanded`), времена |
| `cooldowns[]` | `allianceId: null` — запрет подавать заявки куда-либо (после выхода/исключения), иначе — только в этот союз (после отказа); `until` в мс |
| `diplomacy[]` | Зарезервировано под будущую дипломатию, сейчас всегда пустое |

`joinedAt` фиксируется в реальном состоянии; `creditDeliveredUnits(state, ownerId, units)` — точка входа для PR 2.

Идентичность владельца: `ownerId` (`profile.playerId`, `npc-bot-01`, `member-ira-vel`). Один владелец — один участник независимо от числа планет. Союз владельца для вселенной/шпионажа/профиля всегда **выводится из реестра** (`selectOwnerAlliance`), а не из сохранённых снимков.

## Что сделано

- **Палата.** `selectCommandHallLevel` = максимум `planetary-government` по всем планетам (не сумма). Уровень 0 — экран блокировки с артом здания расы и кнопкой «Перейти к строительству» (открывает карточку Палаты в военной зоне). Потеря Палаты ничего не удаляет; `App` повторно проверяет Палату перед каждым действием.
- **Союзы.** Создание (бесплатно), уникальность названия/тега по миру (без учёта регистра), один владелец — один союз, редактор переиспользуется для создания и правки (карандаш в обзоре).
- **Заявки.** Одна ожидающая заявка на владельца; отзыв без задержки; отказ → 2 ч только в тот же союз; выход/исключение → 2 ч во все союзы; при 15/15 все ожидающие автоматически отклоняются («Нет мест»); принятие перепроверяет актуальность, членство и место.
- **Роли.** Лидер + не более одного заместителя; заместителя назначает только лидер; заместитель управляет союзом и исключает рядовых, но не лидера; лидер может исключить заместителя; выход лидера требует передачи (заместителю по умолчанию или выбранному), единственный участник расформировывает союз.
- **Автопреемство.** Лидер отсутствует > 24 ч → заместитель; иначе доставленные единицы → активность → совместные операции → сохранённый `tieBreaker`. Таймер нового лидера стартует заново (нет «пинг-понга»). Локальный игрок, пока игра открыта, никогда не считается отсутствующим.
- **Рейтинг.** Среднее общих очков участников; средние ресурсные/боевые — отдельные компоненты. Каталог и рейтинг союзов показывают только реальные союзы (в production без союзов — честная пустота). Фикстура очков Иры Вель (1 000 000 / 0 / 1 000 000 / 0) применяется только в Test Mode.
- **Миграция.** v1 → v2: Test Mode пересобирает стартовый союз (игрок-лидер + Ира Вель), сохраняя правки игрока; production сохраняет только реальный (не фикстурный) союз как союз из одного игрока. Фикстурный союз в production-сохранении отбрасывается. Битые данные чинятся, а не роняют загрузку.
- **Убрано.** Выдуманные участники, дипломатические союзы, совместные операции, запросы и события, кнопки «Помочь»/«Присоединиться»; фиктивные «приглашения» в центре сообщений. Вместо них — честные заглушки.
- **CSS.** `src/command.css` переписан: скругления по токенам Asterion, без `clip-path` и декоративных светящихся линий.

## Test Mode

- Стартует с Палатой 1 (roadmap A6 разрешает); production — с 0. Автоматически не восстанавливается.
- Управляемые сценарии (только Test Mode, явные кнопки): «ТЕСТ: ЗАЯВКА ОТ БОТА 01» (вкладка «Заявки») и «ТЕСТ: СОЮЗ БОТА 01» (каталог). Автономных решений NPC нет.

## Решения по неоднозначностям (для проверки владельцем)

1. **Создание союза во время 2-часовой паузы после выхода/исключения запрещено** (доменная проверка в `createAlliance` и отключённая кнопка с таймером). Отказ в заявке в один союз создание своего союза не блокирует.
2. **Расформирование** (выход единственного участника) тоже запускает 2-часовую паузу — как «любой выход».
3. **Заявка в полный союз** не принимается (кнопка «Нет мест»), а не подаётся и сразу отклоняется.
4. **Поле `diplomacy`** оставлено пустым и зарезервированным, чтобы не ломать контракт расчёта отношений в галактике (`war`/`hostile` → враг) до будущего этапа.
5. Сохранённый на цели шпионажа снимок `alliance` игнорируется: союз цели определяется по реестру.
