# Гербы «Орбитальные дома» (v2)

Источник: пакет `ASTERION_ORBITAL_HOUSES_V2` (`assets/source/command-heraldry-orbital-v2/`, 92 PNG по 1254 px, `manifest.json`, `OPUS_HANDOFF.md`). Исходники в репозиторий не входят.

## Сборка рантайм-набора

```
python -I tools/build-orbital-heraldry.py <путь к command-heraldry-orbital-v2>
```

Скрипт сверяет состав плана (6 рамок, 6 эмалей, 8 узоров, 12 знаков × 6 цветов), sha256 каждого PNG и замкнутость внутренних масок рамок, затем пишет:

- `src/assets/command/orbital-heraldry/*.webp` — все модули в 512 px (~3 МБ);
- `src/assets/command/orbital-heraldry/mask-<frame>.png` — маска внутренней области из `interior.runs`;
- `src/domain/command/orbital-crest-catalog.generated.ts` — id, названия, геометрия (pivot/radius, безопасная окружность R).

## Контракт

- Сохраняется конфигурация `emblem.crest` (`version: 2`, `frame`, `field`, `pattern`, `patternOpacity`, `glyph`, `color`, `glyphScale`, `rotation`, `mirrorX`, `offsetX`, `offsetY`), а не картинка. Проверка — `parseCrest` в `src/domain/command/crest.ts`: неизвестные id и числа вне границ отклоняют весь герб.
- Границы: размер знака 0.4R–0.85R (по умолчанию 0.64R), поворот ±180°, смещение не дальше 0.12R, яркость узора 0..1 (по умолчанию 0.6 для созвездия, 0.24 для остальных).
- Старые гербы (`glyph/accent/shape/field/fieldColor`) не конвертируются: они рисуются прежним SVG, пока игрок не применит новый герб в конструкторе.
- Порядок слоёв в `src/ui/command/crest/renderer.ts`: эмаль → узор (обрезка маской) → знак (размещение по безопасной окружности, затем маска) → рамка. Модули грузятся по требованию, готовые композиции кэшируются.

## Интерфейс

«Настройки союза» показывают карточку «Герб союза» и кнопку «Конструктор герба». Конструктор открывается во всё окно: слева живой герб (знак перетаскивается мышью или стрелками), размеры 64/48/32 px и готовые образы; справа вкладки «Знак», «Рамка», «Эмаль», «Узор», «Положение».
