Завершает трёхэтапную систему союзов (PR 1 #94, PR 2 #95). Экономика, полёты и сохранения не менялись; версия `CommandState` остаётся 3.

## Где журнал

Вкладка «Совместные операции» теперь содержит две независимые области: **«Журнал союза»** (`JournalPanel` в `src/CommandView.tsx`) и одну заглушку **«Рейд на Солнце — Появится в будущей версии»** (без кнопок). «Дипломатия» осталась заглушкой. Восьмая вкладка не добавлялась.

## Схема видимости (`src/domain/command/journal.ts`)

`selectAllianceJournal(command, viewerOwnerId, now)` — чистый селектор. Компонент никогда не получает сырой `aidEvents`.

| Условие | Результат |
|---|---|
| нет членства | `no_membership`, 0 событий |
| `now < joinedAt + 2 ч` | `locked` — только `unlocksAt`; ни числа, ни типов, ни авторов, ни времён скрытых событий |
| иначе | события **этого** союза с `event.at > joinedAt` текущего членства (событие ровно в момент вступления скрыто) |

`joinedAt` берётся из реального членства, поэтому выход / исключение / повторное вступление / другой союз начинают историю заново. Порядок: `at` по убыванию, при равенстве — по стабильному ключу; не более 100 строк.

Строка журнала (`JournalEntry`) содержит только вид, время, имя действующего **текущего** участника (иначе «нейтрально»), ресурс из карточки запроса, число единиц и известную причину закрытия. Планет, координат, флотов, id запросов и полётов в ней нет; ключ строки — непрозрачный хеш (`journalEntryKey`), поэтому сырые id событий не попадают в DOM. Заблокированный вид рисует только безразмерный skeleton (`aria-hidden`) и обратный отсчёт.

Это защита интерфейса, селекторов и QA, а не шифрование: локальный файл сохранения владелец машины прочитать может.

## События

| Событие | Производитель | Подпись |
|---|---|---|
| `request_created` | `createResourceRequest` | «Создан запрос ресурсов» |
| `request_cancelled` | `cancelResourceRequest` | «Запрос отменён автором» |
| `request_closed` | `closeRequest` (причина) | выполнен / автор покинул союз / союз расформирован / планета назначения утрачена |
| `aid_launched` | `markRequestHelpStarted` | «Отправлена помощь» + единицы |
| `aid_delivered` | `creditAidDelivery` | фактически принятые единицы; 0 → «Груз не принят планетой» |
| `aid_returned` | возврат рейса с грузом | «Помощь вернулась» |

Событий «совместной операции» нет: производителей нет, рейд — заглушка. Заявки на вступление остаются во вкладках «Союзы»/«Заявки», полёты — в «Флотах».
