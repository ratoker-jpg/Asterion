# Командование — foundation v1

## Visual direction

Композиция экрана согласована по пользовательскому референсу как по направлению: плотный тактический командный центр, secondary tabs, мозаика overview-блоков и list/detail для рабочих разделов. Чужие названия, ресурсы, структура и IP-assets не копируются; визуал адаптирован под текущий dark/cyan язык Asterion.

## Что реально работает

- top-level вкладка `Командование` открывает самостоятельный `CommandView`;
- 6 секций: обзор, участники, запросы ресурсов, дипломатия, совместные операции, настройки;
- `Рейд на Солнце` закреплён как флагманская совместная операция;
- join совместной операции меняет локальный alliance state и сохраняется;
- `ПОМОЧЬ` переводит запрос в локальный статус рассмотрения без списания ресурсов;
- настройки союза валидируются, применяются во всех Command-вкладках и сохраняются;
- переходы `ПОДГОТОВИТЬ ФЛОТ / ОТПРАВКУ` используют существующий root раздела `Флоты`;
- Command хранится внутри `asterion.vertical-slice.v1`, старые saves мигрируют на canonical default, общий Prototype Reset восстанавливает default state.

## Осознанно отложено

- реальное выполнение совместных операций и endgame Sun Raid;
- реальный fleet dispatch и транспортировка ресурсов;
- multiplayer/backend, live notifications и chat;
- реальная союзная экономика/казна;
- реальные дипломатические эффекты, войны, роли и permissions;
- battle integration.

Следующий vertical slice должен подключать operation-aware fleet preparation, не дублируя Fleet/Operations runtime внутри Командования.
