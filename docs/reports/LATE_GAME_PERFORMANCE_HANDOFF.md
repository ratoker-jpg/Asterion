# Производительность поздней игры — handoff

Работа продолжена после безопасной остановки 29.10 и закончена; актуальный итог с цифрами —
`LATE_GAME_PERFORMANCE_2026-10-28.md` (+ JSON рядом).

## Сделано после отчёта (29.10)

- Большие сохранения (≥ 8 млн символов) в настольной игре лежат файлом в профиле, в localStorage — указатель
  (`src/application/save-storage.ts`, `electron/save-store.cjs`). Запись файла асинхронная (UI-поток 20 мс вместо
  125 мс на 58 млн символов), при закрытии окна — синхронный сброс.
- Автосохранение живых тиков: JSON переиспользует текст неизменённых записей (`save-json.ts`, байт в байт как
  JSON.stringify; 190 → ~90 мс в Node) и считается шагами по 8 мс между кадрами (самый длинный шаг ~30–40 мс).
- Очки владельцев читают только свои полёты; пиратские броски не пересобирают списки поражений каждый вызов.
  День 3: постоянная цена вызова 19 → 11 мс, тик в 1 с — p50 ~76 мс (было ~190–220). Дайджесты не изменились.

## Что осталось

1. **Пики решений NPC на дне 3**: одна группа экономических событий стоит 40–100 мс (решения, атаки,
   контекст полезности) — её нельзя разрезать без переделки группы; живой тик в 1 с ещё бывает > 50 мс.
   Следующие шаги: дешевле `settleNpcEconomies` в конце вызова (6,7 мс), `pruneCampaignHistory` (скан шпионских
   отчётов при каждом новом), кандидаты миссий.
2. FPS QA в Electron (скрытое окно) после этих коммитов не перезапускался; отчёт/JSON и описание PR не обновлены
   этими цифрами. Полные логические наборы и `ASTERION_NPC_LONG_HORIZON=1 npm run test:npc` не перезапускались
   после последних трёх коммитов (прогнаны только тесты хранилища/JSON и дайджесты паритета).

## Как продолжить

```bash
npm ci && npm run build
npm run benchmark:late-game -- generate --days=1,2,3 --out=DIR
npm run benchmark:late-game -- generate --from=DIR/late-game-day-3.json --days=5,7 --out=DIR
npm run benchmark:late-game -- measure --fixture=DIR/late-game-day-3.json --hours=1 --max-groups=2048
npx electron electron/late-game-fps-qa.cjs --fixture=DIR/late-game-day-2.json --catchup-hours=1 --seconds=8
```

Паритет: дайджест полного мира 6 ч `8ce7cafe…`, мир дня 1 + 30 мин `cb6df959…`, дня 2 + 30 мин
`7c97283b…` (фикстуры свои: дайджесты действительны только для тех же файлов, сравнивайте две ревизии
на одной фикстуре). «До» — тот же скрипт в выгрузке main (`git archive da25bba`); чтобы main открыл
фикстуры из Node, нужен только `src/domain/pirates/contact.ts` из этой ветки.
