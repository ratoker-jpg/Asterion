# Handoff: PR «Сообщения, отчёты и окно прогона» (аудит 26.10, PR 1)

Ветка `claude/messages-reports`. Работа остановлена по просьбе владельца (безопасная остановка).

## Сделано
- **M1** — воспроизведено тестом (`npc-missions.integration.test.ts`): возврат NPC и «Наблюдение NPC сохранено у владельца» проходили фильтр видимости флотов, который управлял тостами. Новый `isFlightEventForPlayer` (`src/application/flight-visibility.ts`): игрок получает свои события и бой на своей планете; видимость входящих флотов на экране «Флоты» не тронута. Текст атаки NPC на игрока больше не говорит «Bot 01». Утечек из перенаселения/переработки/газа не найдено (источники только для планет игрока).
- **M2** — «Итог полёта» (`src/domain/exploration/report-items.ts`): имя планеты, исход по-русски для каждого completionReason, вернувшийся флот (для атаки — выжившие из боевого отчёта), реальная добыча, зачисленное и сгоревшее при переполнении (новое поле `FlightRecord.cargoSettlement`, повреждённое отбрасывается при загрузке), «данные недоступны» для старых сохранений. Убраны технические id из отчётов (BattleReport id, contactCycleKey, flightId, ISO-даты).
- **M3** — бой с 0 раундов: «ЗАХВАТ БЕЗ БОЯ», «Планета захвачена без боя: обороны не было. Добыча: …» (`noCombatVerdict`).
- **M4** — окно прогона: центральная модалка поверх шапки, прогресс/ожидание/блокировка приказов; после прогона — сводка мира (бои, колонии, уничтоженные планеты, союзы, войны/перемирия/пакты, рейды на Солнца, кристаллы, лидеры и рост очков). Сводка копится в `npcReplay.summary`, бои считаются перед каждым прореживанием истории, переживает разбиение и перезагрузку; старое сохранение посреди прогона → пометка «неполная». Electron QA `npc-replay-qa.cjs` обновлён (модальность, центр, перекрытие шапки, сводка, закрытие), `visual-capture.cjs` закрывает сводку.
