## 3. Fleet QA

- **Исходно:** в аудите два разных таймаута. У меня до исправления: 1 успешный прогон из 8, падения в разных местах (`Недостаточно газа`, `flight-preview-open`).
- **Корневая причина (доказана):** обвязка подменяет сохранение *работающей* игры и перезагружает страницу, а автосохранение старой страницы успевает записать своё состояние поверх подмены до перехода. В логах: подмена газа на 0 после перезагрузки читалась как 189 000 000; засеянный пустой список полётов возвращался со старым транспортом. Это дефект обвязки, не игры (игрок не правит localStorage вручную; второе окно игра принимает через storage-event).
- **Исправление:** после своей подмены старая страница больше не может писать ключ сохранения; при таймауте лог печатает достигнутое состояние страницы.
- **Подтверждение:** 5/5 подряд зелёных прогонов, затем ещё прогон в общем наборе (раздел 5).
- Такой же шаблон «подмена + reload» есть в `integration-spaceport-upgrades`, `repair-workshop-qa`, `test-mode-qa`, `visual-capture`, `visual-recycling-center`, `visual-trade-center` — они сейчас проходят; при появлении нестабильности применить тот же приём.

## 7. Файлы, коммиты, риски, что проверить перед merge

Коммиты (по порядку): F-01/F-04 → F-02 → F-09 → F-03/F-06 → SAT-01 → PH-01 → F-07 → F-08 → Fleet QA → Electron QA сохранений. 40 файлов (`git diff -w`: +1950/−148).

**Риски:**
- **Баланс боя (одобрено владельцем):** спутники меняют исход обороны и пиратских налётов; Фантом сильнее в длинных боях.
- **Экономика:** офлайн-игрок получает доход по новым уровням с момента завершения — это и есть правило владельца; онлайн-игроков не касается.
- **Сохранения:** более строгая проверка теперь отказывает сохранениям со структурными повреждениями, которые раньше «тихо» превращались в новую кампанию. Легаси-частичные сохранения без `planets` по-прежнему загружаются.

**Что проверить независимому аудитору:**
1. Electron: «Продолжить»/«Загрузить»/автостарт на испорченном слоте — отказ, байты целы, экспорт работает.
2. Долгая офлайн-сверка с несколькими постройками и наукой на 2+ мирах против посещения каждый час.
3. Отмена науки, оплаченной другой планетой, и уничтожение планеты-плательщика с каскадом.
4. Пиратский налёт на планету со спутниками: отчёт, количество спутников, энергия, обломки, перезагрузка.
5. Фантом: seeded-бой, где он гибнет в раунде 1, — отмены в раундах 2+.
6. `npm run test:inventory` и CI на HEAD PR.
