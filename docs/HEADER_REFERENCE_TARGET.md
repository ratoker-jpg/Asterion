# Header visual target

The approved target is the latest three Aegis / Synod / Veyra full-width header mockups from the implementation thread.

Implementation rule: the permanent command header keeps one live React/DOM structure. Decorative race chrome may be raster artwork, but text, values, timer, navigation, icons, hover/focus states and tooltips remain live DOM. Old procedural panel shells must not remain visible under the raster chrome.

This file exists to keep the visual decision explicit while PR #51 is iterated via screenshot QA.
