## Evidence method and status meanings

- Extracted evidence: `src/domain/combat/source-fixtures/{aegis,synod,veyra}-ships.json`, `commanders.json`, and `ship-abilities.json`; each record retains `sourceFile`, `sourcePageId`, source level, selectors, and captured source values. These JSON files are extracted evidence, not the source HTML itself. Raw HTML and source image files are outside this worktree, in the separate Nemexia checkout at the pinned revision.
- Ordinary selectors include `.itemName`, `.itemSubType`, `.imageHolder img[src]`, `.statsBox li` fields, `.costBox li.res{Metal,Crystal,Gas}`, `.currentLevel`, and `.requirementsBox dd[onmouseover]` tooltip. Ordinary ability selector: `.specialAbilitiesBox > ul > li.{abilityClass} > div.specialAbilityTooltipContent`; tooltip lines retain normalized visible text.
- “Source values” records captured source values. “Asterion value/evidence” points to the current canonical implementation entry and human-facing name/role/art mapping. Mechanical values are in `src/domain/combat/faction-ship-data.ts`; presentation mapping is in `src/domain/combat/faction-catalog.ts`. `Matches` indicates current catalog transcription matches source identity and captured fields; time is deliberately governed by Time Rebalanced. Automated assertion coverage must be verified separately.
- `N/A` means the source page has no field (not zero); intentional for solar satellite cargo/speed/fuel here. `UNKNOWN` means evidence or semantics do not resolve safely.
- For compactness, the 39-row table does not repeat the full source description or exact source icon `src`; both remain recorded in each evidence fixture, together with the source role. The fixture assertion checks the role and mechanics fields against the runtime catalog. Local artwork mapping coverage and its visual limits are documented below.
