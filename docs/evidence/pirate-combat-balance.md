# Pirate combat balance — PR1

Generated 40,500 seeded battles across 135 matchups; 300 runs per matchup.
Seed corpus: `asterion-pirate-combat-v1`; each battle seed includes faction, score band, attacker tech, formation, and run index.

## Scope and limits

This run checks neutral pirate ship statistics, the shared six-class matchup table, score-profile sampling, and the once-per-round Ripper ability. It does not simulate contact frequency, travel, incoming raids, planet siege, or planet destruction; those belong to later PRs.
Each side targets 10,000 combat population. Integer ship counts can leave a small population difference. Player and pirate ship levels are matched to the score profile (0–10); player technology is independently checked at levels 0, 5, and 10.
