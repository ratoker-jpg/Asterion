# Расовая подсветка интерфейса

Первое применение — шапка «Ядро» (`src/ui/header/`). Этот документ — правило для будущего визуального прохода по всем экранам, чтобы интерфейс «перекрашивался» под расу игрока одинаково везде.

## Идея

Базовый интерфейс Asterion остаётся общим: тёмные панели, циановые (`#56d9f2`) рамки и тонкие линии, цвета состояний (зелёный «норма», жёлтый/оранжевый «внимание», красный «опасно»). Раса **не** перекрашивает весь интерфейс — она окрашивает только то, что сейчас **выбрано, активно или принадлежит игроку**: выбранную кнопку, подчёркивание, свечение, шкалу. Так экран сразу читается как «мой», а цвета состояний не теряют смысла.

Цвет берётся из эмблемы расы (`assets/source/generated-factions-v1/factions/*_emblem.png`).

## Палитра

| Раса | `data-faction` | Акцент (основной) | Светлый акцент | Свечение | Рисунок ободка |
|---|---|---|---|---|---|
| Астеры | `aegis` | `#5f9bff` светло-синий | `#b4ceff` | `rgba(95,155,255,.45)` | пластины `46 6` |
| Илары | `synod` | `#3fdc86` светло-зелёный | `#b5ffd6` | `rgba(63,220,134,.42)` | узлы `2 5` |
| Рой | `veyra` | `#ff5468` светло-красный | `#ffb7b0` | `rgba(255,84,104,.42)` | сегменты `18 4 6 4` |

Токены объявлены на `:root[data-faction]` в `src/ui/race/race-tokens.css`. `App` ставит `data-faction` на `<html>` и на `.stage`, поэтому их видят и порталы, и диалоги:

```css
--race-accent         /* светлый акцент: обводка активного, стрелки, начало подчёркивания */
--race-accent-strong  /* основной акцент: шкалы, ободки, заливка активного, конец подчёркивания */
--race-glow           /* мягкое свечение вокруг активного */
--race-bezel-dash     /* рисунок пунктира ободков (stroke-dasharray) */
--race-border, --race-border-soft      /* рамки «своих» элементов */
--race-fill, --race-fill-soft, --race-outline, --race-underline   /* производные для рецепта */
```

Шапка читает их через свои имена `--header-*` (`src/ui/header/header.theme.css`).

## Где применено

Все экраны перекрашены одним слоем `src/ui/race/race-theme.css` (подключается последним, правила под `:root[data-faction]`). Там по разделам: вкладки и сегменты, фильтры и пагинация, вертикальная навигация и выбранные строки, выбранные плитки, прогресс своих построек и очередей, своя планета на карте. Новый экран добавляет свои активные селекторы в этот же файл, а не красит расу в собственном CSS.

## Рецепт «активной» кнопки

Именно так выглядит выбранный раздел в шапке (`.hdr-route.active`), и так же должны выглядеть выбранные вкладки, сегменты, фильтры и карточки на других экранах:

```css
.some-tab.active {
  color: #fff;
  /* лёгкая заливка расой сверху, уходящая в прозрачность */
  background: linear-gradient(180deg, color-mix(in srgb, var(--race-accent-strong) 22%, transparent), transparent);
  /* тонкая обводка светлым акцентом */
  box-shadow: inset 0 0 0 1px color-mix(in srgb, var(--race-accent) 60%, transparent);
}
/* иконка внутри: круг с заливкой расы, обводка 2px светлым акцентом и свечение */
.some-tab.active .icon {
  background: radial-gradient(circle at 50% 32%, color-mix(in srgb, var(--race-accent-strong) 34%, #13252c), #0a171c 74%);
  box-shadow: inset 0 0 0 2px var(--race-accent), 0 0 18px var(--race-glow);
}
/* подчёркивание: от светлого к основному */
.some-tab.active .label::after {
  height: 3px; border-radius: 2px;
  background: linear-gradient(90deg, var(--race-accent), var(--race-accent-strong));
}
```

Наведение (`:hover`, `:focus-visible`) остаётся **нейтральным** — `rgba(86,217,242,.06)` и белый текст. Раса появляется только при выборе, чтобы её цвет означал «выбрано».

## Что окрашивать расой

- выбранный раздел, вкладку, фильтр, сегмент, выбранную строку списка (как выбранная планета в списке планет);
- шкалы-«владения» игрока: заполнение склада в ядре, прогресс своих построек и очередей;
- ободки и рамки «своих» крупных объектов (ядро с планетой, портрет командира, своя планета на карте);
- акцентная линия под шапкой и разделители разделов;
- раскрывающие стрелки (шевроны) у своих выпадающих списков.

## Что расой НЕ окрашивать

- цвета состояний и ресурсов: заполнение склада (зелёный → красный), энергия, обломки, ошибки, предупреждения, таймеры опасности;
- цвета зон (ресурсная — циан, промышленная — янтарь, военная — красный) и миссий;
- значок непрочитанных сообщений (красный) и тестовый режим (янтарный);
- основные кнопки действия («Принять операцию», «Отправить флот») — они остаются циановыми, чтобы главное действие выглядело одинаково для всех рас;
- чужие объекты (пираты, другие игроки) — у них свой цвет, а не цвет игрока.

## Опознавательные знаки расы

- Эмблема расы стоит под ядром шапки (74 px). На других экранах эмблему ставить только туда, где речь о самом игроке или его союзе, не как декор.
- Рисунок ободка (`--race-bezel-dash`) — только на круглых «своих» элементах (ядро, портрет, своя планета).

## Как проверить

В тестовом режиме тема всего интерфейса переключается параметром (старый `headerFaction` тоже работает), сохранение не меняется:

```
?mode=test&faction=aegis
?mode=test&faction=synod
?mode=test&faction=veyra
```

В обычной игре раса берётся из `state.profile.factionId`. Когда появится выбор расы, интерфейс переключится сам.
