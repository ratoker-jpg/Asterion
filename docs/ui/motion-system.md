# Asterion — система движения и визуальный язык компонентов

Единый источник правды для анимаций и поведения интерфейса. Новые экраны и
компоненты берут отсюда токены и рецепты, а не придумывают свои значения.

- Токены: `src/asterion-unified-theme.css` (`:root`, блок «Motion system»).
- Игровые экраны: `src/motion.css` (подключается после всех стилей экранов, перед `final-polish.css`).
- Меню, «Новая игра», загрузка, вход в кампанию: `src/ui/menu/menu-motion.css`
  (+ `pointer-depth.ts` — позиция курсора для параллакса и подсветки).
- Звук, который сопровождает движение: `docs/ui/sound-system.md`.
- Общий контракт интерфейса (типографика, радиусы, цвета): `DESIGN.md`.

## 1. Принципы (v2, «голографическое проявление»)

Первая версия держала всё в 120–280 мс и сдвигах 6–10 px — интерфейс работал,
но выглядел неживым. v2 — игровой язык: вещи *прибывают*.

1. **Проявление, а не появление.** Экран, карточка, окно выходят из размытия
   (blur → 0), поднимаются и садятся на пружину (`--ut-spring`). Панели экрана
   идут друг за другом (`sibling-index()`), объекты карты и постройки
   «материализуются» со вспышкой яркости.
2. **Каждый новый экран отмечен.** По рабочей области проходит голографическая
   линия развёртки (`.route-sweep`, App ставит новый ключ на каждый экран) и
   звучит «screen».
3. **Наведение отвечает телом.** Карточка приподнимается на пружине, получает
   глубину и свечение цвета расы, арт внутри выходит вперёд. Только мышь.
4. **Частое не анимируется.** Тики ресурсов, таймеры, ввод, горячие клавиши,
   навигация стрелками — без анимации. Плитки «Флотов» короче и ближе (320 мс).
5. **Только композитные свойства:** `opacity`, `filter` (blur/brightness) и
   отдельные `translate` / `scale` / `rotate`. Они не вызывают раскладку и
   *складываются* с уже заданным `transform`. Элемент, центрированный через
   `transform: translate(-50%,-50%)`, **не получает `scale`** (масштаб идёт
   вокруг его непреобразованной коробки, и он уезжает) — ему анимируют
   прозрачность, фильтр и сдвиг или масштабируют арт внутри. Кольца орбит и
   планета на обзоре анимируются целым `transform` в ключевых кадрах.
6. **Появления — только при монтировании, `animation-fill-mode: backwards`.**
   После окончания у элемента нет остаточной трансформации и фильтра:
   геометрия, `position: fixed` потомков и замер длинной страницы
   (`GlobalPageScrollController`, перемер по `animationend`) не меняются.
   `both`/`forwards` запрещены там, где у свойства есть состояние наведения:
   заполненная анимация перекрывает переход.
7. **Повторный рендер не повторяет анимацию.** Анимация висит на элементе и
   проигрывается один раз, когда React его создаёт.
8. **`prefers-reduced-motion` обязателен.** Остаются короткие затухания;
   исчезают сдвиги, размытие, масштаб, развёртка, параллакс и фоновые циклы.

## 2. Токены

| Токен | Значение | Назначение |
| --- | --- | --- |
| `--ut-spring` | `linear(…)`, перелёт 2% | появления экранов и карточек, наведение |
| `--ut-spring-pop` | `linear(…)`, перелёт 9% | окна, выбор, значки, возврат после нажатия |
| `--ut-ease-out` | `cubic-bezier(0.23, 1, 0.32, 1)` | короткие появления, цвет |
| `--ut-ease-expo` | `cubic-bezier(0.16, 1, 0.3, 1)` | длинные сцены: планета, камера Вселенной |
| `--ut-ease-in-out` | `cubic-bezier(0.77, 0, 0.175, 1)` | движение видимого объекта, блики |
| `--ut-ease-hero` | `cubic-bezier(.22, 1, .36, 1)` | меню и итог кампании |
| `--ut-motion-press` | 140 мс | нажатие |
| `--ut-motion-fast` | 180 мс | цвет и рамка |
| `--ut-motion-base` | 240 мс | вкладки, подъём при наведении |
| `--ut-motion-modal` | 420 мс | окно (пружина) |
| `--ut-motion-item` | 460 мс | карточки каталога |
| `--ut-motion-screen` | 560 мс | экран или раздел |
| `--ut-motion-sweep` | 760 мс | линия развёртки |
| `--ut-stagger` | 55 мс | шаг между соседями |
| `--ut-rise` / `--ut-rise-small` | 22 / 14 px | подъём экрана / карточки |
| `--ut-blur-in` | 8 px | размытие на входе |
| `--ut-lift` | −4 px | подъём карточки при наведении |

## 3. Рецепты

| Ситуация | Как выглядит | Где |
| --- | --- | --- |
| Экран (маршрут, раздел «Флотов», интерьер, зона, утилиты) | из размытия 8 px и яркости 135%, подъём 22 px, 98,5% → 100%, 560 мс на пружине; панели внутри — следом с шагом 55 мс | `ut-screen-in`, `ut-rise-in` |
| Новый экран в рабочей области | линия развёртки сверху вниз за 760 мс и лёгкая заливка цвета расы | `.route-sweep` |
| Обзор планеты | кольца орбит въезжают с поворотом и затем медленно вращаются (240 и 360 с), планета выходит из яркого размытия, панели — слева, справа и снизу, плашки зон вспыхивают по очереди | §4 `motion.css` |
| Вселенная | камера «подлетает» (108% → 100% из размытия), планеты материализуются по орбитам, панели радара пристыковываются с краёв | §5 |
| Зона планеты | постройки возводятся по очереди: подъём с земли из яркой вспышки; при наведении здание подпрыгивает на пружине, тень загорается цветом расы | §6 |
| Шапка | при входе в кампанию ячейки и вкладки включаются по очереди; иконка вкладки под курсором приподнимается и светится, новая активная «щёлкает» | §7 |
| Карточки каталога | по очереди из размытия, первые 10 с шагом 55 мс | `ut-item-in` |
| Наведение на карточку (только мышь) | подъём 4 px, глубина и свечение расы, арт 106%; длинные строки только сдвигаются на 4 px вправо | §3 |
| Окно | подложка проявляется, панель пружинит из 90% и яркого размытия, содержимое идёт следом | `ut-pop-in` |
| Уведомление | выезжает слева из размытия на пружине; под ним тает полоска оставшегося времени (3 с) | `ut-toast-in`, `ut-life` |
| Идёт работа (очередь, переработка, Врата, заказы флота) | по заполненной части бежит блик раз в 2,4 с | `ut-sheen` |
| Требует внимания | `.ut-attention`: два спокойных пульса | `ut-attention` |
| Живой фон | два слоя звёзд мерцают и медленно дрейфуют | `ut-twinkle`, `ut-drift` |

### Меню и «Новая игра» (`menu-motion.css`)

Редкие экраны, поэтому здесь можно кинематографично (до ~1,5 с):

- **Глубина:** фон, звёзды и фигуры генералов смещаются за курсором с разной
  глубиной; на карточке под курсором (пункты меню, расы, слоты, витрина)
  движется мягкое световое пятно.
- **Логотип:** собирается из широкой разрядки и размытия, затем по нему
  проходит блик (повтор раз в 9 с); линия под ним прорисовывается, по ней бежит свет.
- **Пункты меню:** въезжают слева по очереди; при наведении — сдвиг на
  пружине, номер вспыхивает, заголовок раздвигается.
- **Выбор расы (эталон):** карточки поднимаются из яркого размытия по одной;
  под курсором колонка расширяется, фон уходит против курсора, генерал
  наклоняется к нему, стартовый флот «рапортует» (иконки по очереди). Выбор —
  ударное кольцо, вспышка карточки и «зарядка» генерала; по рамке выбранной
  карточки постоянно бежит свет.
- **Мир и подтверждение:** панели въезжают с разных сторон, атлас галактик
  проявляется по одной, у героя медленный «Кен Бёрнс», кнопка «Начать игру»
  дышит светом, и по ней пробегает блик.
- **Вход в кампанию:** `LaunchOverlay` — вспышка, ударное кольцо и звёздные
  росчерки поверх уже смонтированной игры (1,5 с, ввод не блокируется); в это
  же время шапка и планета собираются своими появлениями.

Чтобы новый экран получил появление, достаточно отрендерить его корнем внутри
`.workspace`, `.fleet-main-v1`, `.utility-screen-host` или
`.building-interior-host`. Чтобы карточки появлялись по очереди, их класс
добавляется в списки раздела 3 в `motion.css`, больше ничего не нужно.

## 4. Кнопки и интерактивные элементы

| Состояние | Поведение |
| --- | --- |
| Наведение (только мышь, `@media (hover: hover) and (pointer: fine)`) | цвет, рамка и фон меняются за 180 мс. **Основные действия** приподнимаются на 2 px, становятся на 14% ярче и отбрасывают свечение цвета расы; по основным кнопкам меню ещё и пробегает блик |
| Нажатие | любая включённая кнопка сжимается до 96% за 90 мс и пружинит обратно (`--ut-spring-pop`); крупные объекты карты, участки зданий, карточки рас и пункты меню — до 98,5% |
| Фокус с клавиатуры | голубая обводка `--ut-focus` (2 px `--ut-accent`) со смещением 2–3 px |
| Выключена | без движения, прозрачность 0,4, курсор `not-allowed` |

Иерархия кнопок (цвета из `DESIGN.md`):

- **Основная** (одна на экран или окно: «Отправить», «Построить», «Объявить рейд», «Заказать уровень»): голубая заливка `--ut-accent` или цвет расы, белый текст 12 px с капсом и разрядкой .08–.12em, радиус `--ut-r-btn`. Список классов основных кнопок — в разделе 10 `motion.css` (и в `CLICK_RULES` звука в `src/audio/ui-bindings.ts`); новая основная кнопка добавляется туда.
- **Вторичная** («Отмена», «Мин./Макс.», переключатели): тёмная поверхность `--ut-surface-2`, рамка `--ut-border`, при наведении `--ut-border-strong`.
- **Опасная** (закрыть, удалить, отменить задание): красная `--ut-danger`; закрытие — красный крестик 18 px в зоне нажатия 40 px.
- **Плитка-переключатель** (миссии, разделы, фильтры): выбранная — заливка цвета расы слева направо и полоска 3 px слева (рецепт из `race-theme.css`).

## 5. Поверхности

- Панель экрана: `--ut-surface`, радиус `--ut-r-panel`, одна рамка `--ut-border`.
- Карточка внутри панели: `--ut-surface-2`, радиус `--ut-r-card`.
- Плашка-счётчик (В СТРОЮ, ДОСТУПНО, УРОВЕНЬ): ширина по содержимому с минимумом, внутренний отступ не меньше 12 px по горизонтали, текст никогда не касается рамки (см. `final-polish.css`).
- Строка статуса в карточке каталога — фиксированной высоты: заказ или блокировка не меняют высоту карточки (так устроены «Наука» и «Космодром»).

## 6. Раскладка и стабильность

- Сцена 1920×1080 всегда центрирована по `50vw` и стоит на одной высоте
  (`--asterion-stage-top`) — и в обычном режиме, и в режиме длинной страницы.
  Экраны не переключают режим длинной страницы сами: это делает только
  `GlobalPageScrollController`.
- Никаких захардкоженных высот страниц; никаких резервов под полосу прокрутки.
- Фон одинаковый в обоих режимах: звёздное небо — один кадр 1920×1080 в верхней
  части сцены, живой слой звёзд поверх.

## 7. Чек-лист для нового экрана или компонента

- [ ] Цвета, радиусы и длительности берутся из токенов `--ut-*`.
- [ ] Корень экрана рендерится внутри одного из контейнеров раздела 3, без собственной анимации появления.
- [ ] Если есть каталог карточек — их класс добавлен в списки появления и наведения.
- [ ] Центрированный через `transform` элемент не получает `scale` в анимации.
- [ ] Если у экрана есть особый звук или окно — см. `docs/ui/sound-system.md`.
- [ ] Основная кнопка добавлена в список основных действий (подъём при наведении).
- [ ] Окно использует пару «подложка + панель» из раздела 3.
- [ ] Ничего, что обновляется каждую секунду, не анимируется.
- [ ] Проверено с `prefers-reduced-motion: reduce`.
- [ ] Текст не касается рамок при больших числах (аудит на нагрузочном сохранении).
