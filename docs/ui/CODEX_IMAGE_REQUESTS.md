# Asterion — заказ картинок для генератора (Codex)

Цель: закрыть места, где интерфейс держится на заглушках или пустоте. Каждый пункт —
самостоятельное задание: промпт можно копировать целиком. Готовые файлы класть в
`assets/source/New assets/ui/<папка из пункта>/` с указанным именем — подключу сам.

## 0. Общий стиль (вставлять в начало КАЖДОГО промпта)

```
Style: Asterion sci-fi strategy game UI art. Painterly-realistic digital painting,
the same look as existing Asterion key art (armored faction generals, glowing planets,
deep-space nebulae). Dark space backdrop #020810 to #0b1720, cinematic rim light,
soft volumetric glow, fine detail, high contrast, no film grain.
Faction palettes when relevant: Asters (aegis) steel blue #5f9bff / #b4ceff,
Ilary (synod) emerald #3fdc86 / #b5ffd6, Swarm (veyra) crimson #ff5468 / #ffb7b0.
UI accent cyan #56d9f2, amber #e6ad50 for warnings.
Hard rules: NO text, NO letters, NO numbers, NO logos, NO watermarks, NO UI frames,
NO borders, NO people unless asked, centered composition, clean edges.
```

Общие требования к файлам:
- PNG (прозрачность — где указано) или WebP без потерь; sRGB; без встроенного текста.
- Размер — ровно как указано (не меньше): интерфейс рисуется на сцене 1920×1080 и
  масштабируется вниз до 1280×720.
- По 3 варианта на пункт — выберу лучший.

## 1. Галактики для атласа «Новая игра → Мир» (приоритет 1)

Сейчас атлас рисуется кодом (спираль, ядро, туманность). Картинка-подложка сделает его
«как в кино»: систем-точки и метки остаются поверх.

- Папка `atlas/`, имена `galaxy-01.png` … `galaxy-05.png` (5 разных галактик, цикл по номеру).
- 1024×1024, **прозрачный фон** за пределами галактики.
- Промпт: `Top-down view of a two-armed barred spiral galaxy, seen almost face-on with a
  slight 20° tilt (ellipse ratio 0.82). Bright warm white-gold core, two spiral arms
  making about two full turns, blue-white star clusters along the arms, dark dust lanes,
  faint {COLOR} nebula clouds between the arms. The galaxy fills a circle of 92% of the
  canvas, fades softly to fully transparent at the edge. Transparent background.`
- `{COLOR}` по файлам: 01 — синий, 02 — фиолетовый, 03 — бирюзовый, 04 — малиновый, 05 — янтарный.
- Важно: рукава закручены **против часовой стрелки**, центр строго в центре кадра.

## 2. Баннеры миссий для окна «Подробности рейса» (приоритет 1)

Шапка окна рейса сейчас пустая. Узкий кинематографичный баннер на каждую миссию.

- Папка `missions/`, 1440×360 (соотношение 4:1), PNG без прозрачности, тёмный левый край
  (там будет текст) — основной объект в правой трети.
- Имена и сюжеты (`banner-<id>.png`):
  - `attack` — строй боевых кораблей выходит из гиперпрыжка к вражеской планете, залп лазеров;
  - `transport` — грузовые корабли с контейнерами летят между двумя своими планетами;
  - `recycle` — корабли-переработчики собирают светящиеся обломки на орбите;
  - `gas` — корабли с цистернами у астероида, газовые шлейфы;
  - `colonize` — колонизатор спускается к необжитой планете, свет посадочных огней;
  - `espionage` — маленький зонд-шпион в тени планеты, сканирующий луч;
  - `expedition` — флот у таинственного древнего объекта или аномалии;
  - `deployment` — флот встаёт на орбите своей планеты-базы;
  - `space-flight` — флот уходит в глубокий космос, пустота и далёкие туманности;
  - `aid` — караван союзников доставляет ресурсы, мягкий зелёный свет;
  - `sun-support` — корабли защиты на фоне пылающего солнца;
  - `pirate-elimination` — штурм пиратской базы-астероида.
- Промпт-шаблон: `Wide cinematic banner, {SCENE}. Main subject in the right third, left
  40% of the frame fades to near-black space for overlay text. Painterly sci-fi, dramatic
  rim light, depth of field.`
