# Asterion — звуковая система

Звук в игре **синтезируется на лету** через Web Audio API: ни одного аудиофайла,
ни одной зависимости, ноль байт в сборке. Это даёт полный контроль над громкостью,
мгновенный отклик и единый «голос» игры. Позже любой синтезированный звук можно
заменить сэмплом (раздел 6) — интерфейс движка для этого уже готов.

| Файл | Что делает |
| --- | --- |
| `src/audio/engine.ts` | один `AudioContext`, шины, компрессор, реверберация, ограничение повторов, музыка |
| `src/audio/sounds.ts` | палитра: 20 звуков-рецептов (`SOUNDS`) |
| `src/audio/music.ts` | генеративная фоновая музыка (`menu`, `game`) |
| `src/audio/ui-bindings.ts` | глобальная привязка: клики, наведение, окна, уведомления, смена экрана |
| `src/audio/hooks.ts` | `useMusic`, `useSoundOnIncrease`, `useAudioPreferences` |
| `src/domain/settings/audio.ts` | настройки громкости (ключ `asterion.audio.v1`), тесты в `npm run test:settings` |
| `src/SettingsView.tsx` → «Звук» | общий уровень, музыка, события, интерфейс, выключение, тест |

## 1. Граф

```
effects   ─┐
interface ─┼─> master ─> compressor ─> динамики
music     ─┘      ^
reverb (сгенерированный импульс 2,8 с) ─┘   (любой голос может отправить в него часть сигнала)
```

- Контекст создаётся **по первому жесту** (pointerdown/keydown) — политика автозапуска
  Chromium. Синтетические `.click()` из QA-скриптов жестом не считаются, поэтому
  Electron-тесты идут без звука.
- Свернули окно → контекст приостановлен (ноль CPU), вернулись → продолжает.
- Громкость шины = `1.6 × (master × channel)²` — квадратичная кривая похожа на
  слух; при выключении или нуле музыка не просчитывается вовсе.

## 2. Палитра (`SOUNDS`)

«Холодное стекло и низкий гул корпуса». Каждый голос — короткая огибающая
(экспоненциальный спад до 0,001, остановка с запасом 10 мс): ничего не щёлкает
и не тянется. Уровни — по границам скилла ui-sound-design.

| Звук | Когда | Характер |
| --- | --- | --- |
| `hover` | курсор на вкладке шапки, объекте карты, кнопке меню | дыхание стекла, 50 мс |
| `hoverCard` | курсор на крупной карточке меню (пункт, раса, слот) | воздушный шорох |
| `click` | любая кнопка | щелчок + короткий тон |
| `tab` | вкладки, разделы, фильтры, сегменты | восходящий «тик» |
| `confirm` | основное действие (построить, исследовать, отправить, «Далее») | восходящая квинта с телом |
| `back` | «Назад», закрыть | нисходящий тон |
| `heavy` | удалить, опасные действия | низкий удар корпуса |
| `toggleOn` / `toggleOff` | переключатели | вверх / вниз |
| `tick` | шаг ползунка | сухой тик |
| `open` / `close` | окно появилось / исчезло | вздох вверх / вниз |
| `screen` | новый экран (линия развёртки) | низкая волна и далёкий блик |
| `info` | обычное уведомление | одна стеклянная нота |
| `success` | уведомление об успехе | арпеджио из трёх нот |
| `error` | ошибка | два низких «бззт» |
| `notify` | новый отчёт или сообщение | двойной колокол |
| `alarm` | входящая атака, атака на Солнце | двухтоновая тревога ×2 |
| `select` | выбор расы | удар и долгий кристаллический звон |
| `launch` | вход в кампанию (вместе с варп-переходом) | глубокий удар, рывок, хвост |

Повторы гасятся окном `MIN_REPEAT_MS` (наведение, тревога раз в 2,5 с, отчёты
раз в 0,6 с) — догон NPC или пачка отчётов не превращается в пулемёт.

## 3. Что звучит само

`ui-bindings.ts` слушает документ целиком, ни один экран не импортирует движок:

1. `data-sfx="<id>"` на элементе или предке задаёт звук явно, `data-sfx="none"` глушит.
2. Иначе — таблица `CLICK_RULES` (селекторы → звук), затем `click` по умолчанию.
3. Наведение — таблица `HOVER_RULES`, только мышь, один раз на вход в элемент.
4. `MutationObserver`: появилось окно (`DIALOGS`) → `open`, исчезло → `close`;
   появился `.runtime-toast` → по тону (`success` / `error` / `info`);
   новый ключ `.route-sweep` в рабочей области или новый экран в
   `.utility-screen-host`, `.fleet-main-v1`, `.building-interior-host`, меню → `screen`.
5. Из App: `useSoundOnIncrease(входящие атаки + атаки на Солнца, 'alarm')`,
   `useSoundOnIncrease(непрочитанные отчёты, 'notify')` — только при росте, не при загрузке.

Новая основная кнопка → добавить её селектор в `CLICK_RULES` (`confirm`) и в
список основных действий `motion.css` §10. Новое окно → его подложку в `DIALOGS`.

## 4. Музыка

Генеративный эмбиент без зацикленного файла: медленные аккорды (два
расстроенных голоса на ноту, нарастание 3–4 с) под «дышащим» фильтром, суб на
корне, редкие кристаллические колокола через тёмную задержку. Порядок аккордов
и ноты колоколов выбираются заново каждый цикл — точного повтора нет.

- `menu` — ре дорийский (Dm9 · B♭maj7 · Gm9 · A7sus4), аккорд 11 с, колокола чаще.
- `game` — до эолийский (Cm9 · A♭maj7 · Fm9 · Gsus4), аккорд 15 с, темнее и реже.
- Меню → игра: старая тема гаснет 3 с, новая нарастает 4 с.

## 5. Настройки

`Настройки → Звук`: общий уровень, музыка, события, интерфейс (0–100, шаг 5),
выключение звука, «Проверить», «По умолчанию». Хранятся отдельно от интерфейса
и кампании (`asterion.audio.v1`), применяются сразу. По умолчанию: 90 / 55 / 75 / 60.

## 6. Следующий шаг: сэмплы, сгенерированные нейросетью

Синтез закрывает интерфейс полностью. Для «киношных» моментов (залп флота,
взрыв, вход в кампанию, музыкальная тема) можно позже добавить сэмплы:

1. **Сгенерировать.** ElevenLabs Sound Effects (текст → звук, до 22 с, лицензия
   на коммерческое использование в платных тарифах), Stable Audio 2.x или
   AudioCraft/AudioGen (локально, MIT/CC-BY-NC — проверить лицензию весов). Для
   музыки — Suno/Udio (коммерческие права только на платных планах) или
   Stable Audio. Промпт: «sci-fi UI confirm, glassy, short, 0.3s, no reverb tail».
2. **Подготовить.** Обрезать тишину, нормализовать до −16 LUFS (эффекты) и
   −22 LUFS (музыка), моно для UI, OGG Vorbis/Opus 96–128 кбит/с, имя = id звука:
   `public/audio/sfx/confirm.ogg`, `public/audio/music/game.ogg`.
3. **Подключить.** В движок добавляется загрузчик: `fetch` → `decodeAudioData`
   один раз при разблокировке, буферы в `Map<SoundId, AudioBuffer>`. В `play(id)`:
   если для id есть буфер — проиграть `AudioBufferSourceNode` в ту же шину (и
   в реверберацию при желании), иначе — синтезированный рецепт. Так замена идёт
   по одному звуку, без переделки привязок и настроек.
4. **Музыка из файла.** `music.ts` получает третий режим: зацикленный буфер
   (`loop = true`, `loopStart/loopEnd` по сетке тактов) через ту же шину и
   тот же кроссфейд 3 с.
5. **Проверить.** `npm run build` (файлы из `public/` попадают в `dist/`),
   электронная сборка — `dist/**/*` уже в `files`, отдельной настройки не нужно.

Оценка: загрузчик и подмена — ~0,5 дня кода; основное время — генерация и
отбор звуков (по 3–5 вариантов на звук).
