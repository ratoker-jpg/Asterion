# Asterion — канон зданий по расам

Статус: рабочая версия для утверждения названий и сопоставления с ассетами.

## Канонические названия рас

- **Астеры**
- **Илары**
- **Рой**

> Старые технические названия графических пакетов не являются названиями рас Asterion и должны быть удалены из пользовательской терминологии и позже переименованы в структуре репозитория.
>
> Ниже они могут встречаться **только внутри текущего точного пути к PNG**, потому что файлы в репозитории пока физически называются так. Это временный legacy-путь, а не игровое название расы.

## Общая структура

Для каждой расы используется одинаковая функциональная сетка из 24 building-assets:

- **Ресурсная зона — 10 зданий**
- **Промышленная зона — 7 зданий**
- **Военная зона — 5 зданий**
- **Особые здания — 2 здания**

# Примечания для будущей очистки репозитория

1. Игровые названия рас: **Астеры / Илары / Рой**.
2. Старые названия графических пакетов не должны использоваться в UI, документации, игровых текстах, конфигурациях и новых идентификаторах.
3. Текущие PNG-пути пока сохранены в этом документе исключительно для точного сопоставления существующих файлов.
4. При отдельной миграции ассетов нужно переименовать директории и filenames, сохранив связь по `Asset-role`.
5. `Asset-role` (`metal-production-1`, `research`, `shipyard` и т. д.) сейчас является самым надёжным нейтральным ключом для сопоставления между расами.
6. Механика двух особых зданий (`galactic-obelisk` и `supreme-galactic-gates`) пока не утверждена — здесь зафиксированы только названия и соответствующие изображения.
