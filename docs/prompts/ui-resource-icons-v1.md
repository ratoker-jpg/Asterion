# Asterion — production UI icons v1

This is a future asset-generation task. The current build uses procedural inline SVG icons so development is not blocked.

Generate a coherent Aegis UI icon set with transparent backgrounds for:

- metal
- minerals
- gas
- energy
- population
- resource zone
- industrial zone
- military zone

## Requirements

- 8 independent PNG files
- 512×512 RGBA
- fully transparent background
- no text
- no frame baked into the image
- centered readable symbol with generous transparent padding
- premium dark sci-fi strategy style
- Aegis palette: cyan/blue base, with restrained category accents
- must remain readable at 24–48 px UI size
- clean silhouette, high contrast, no photographic background

- `assets/source/ui-icons/aegis/resource-gas.png`
