# Asterion: единый стиль иконок и мелкой графики

Утверждён в PR «Новые иконки: шапка, вкладки и миссии» (пакет 1, 14.11.2026). Все следующие пакеты плана `ASSET-AUDIT-2026-11-14.md` делаются по этому файлу. Старые наборы (плоские светящиеся глифы в квадратных рамках `mission-icons-v1`, разношёрстные иконки шапки) после замены в игре не используются.

## Как выбирали

Три пробы одного набора («Флоты», «Металл», «Атака») на тёмной полосе шапки в 128, 48 и 24 px:

- **A. Светлый полированный металл + бирюзовая эмаль** — выбран. Светлое тело даёт силуэт, который читается и в 24 px.
- B. Глянцевая цветная эмаль — читается, но голубое тело сливается с бирюзой интерфейса, ресурсы теряют свой цвет.
- C. Тёмный оружейный металл со светящейся кромкой — в 24 px остаётся только контур, хуже всех (это же было замечено у первой пробы «Флотов» из #232).

## Правила

| Что | Правило |
|---|---|
| Материал | Полированный светлый серебристо-белый металл, чистые фаски, глянцевые блики. |
| Акцент | Бирюзовая светящаяся эмаль (около `#3fe3f0`) во вставках, линзах, ядрах. |
| Сигнальный цвет | Только когда предмет его требует: ресурсы (металл — сталь, минерал — сапфир, газ — изумруд, энергия — янтарь), рейтинг — золото, Солнце — оранжевый, пираты — красные глаза. Один такой цвет на иконку. |
| Свет | Ключевой свет сверху слева, тонкий бирюзовый контровой свет по краю. Широкого ореола нет: он даёт рваную полупрозрачную кайму. |
| Силуэт | Один-два крупных объёма, мало мелких деталей. Предмет занимает около 85% холста. Без подложки, рамки, круглого медальона. |
| Объём | Трёхмерная подача в лёгком ракурсе, но без перспективных сцен и окружения. |
| Фон | Прозрачный, генерируется сразу с альфой (`hasAlpha: true`). Фон потом не вырезаем. |
| Текст | Никакого текста, букв, цифр. Не подражать играм, брендам, художникам. |
| Читаемость | Проверять листом 128/48/24 px на тёмном `#090d14` и на пурпурном (кайма альфы). В 24 px предмет должен узнаваться. |
| Формат в игре | WebP с альфой, поля обрезаны до предмета + 3%, 128×128 (иконки) или по месту показа (`debris-finder` 96, `mission-sun-raid` 256). Исходник PNG лежит в `assets/source/ui/icons-v2/` и в сборку не попадает. |

## Базовый текст промпта

Подставить предмет в `{SUBJECT}`, остальное не менять:

```
Game UI icon for a dark sci-fi space strategy game. Subject: {SUBJECT}. House style: polished light silver-white metal with glowing cyan enamel accents, clean bevelled 3D forms, glossy specular highlights, key light from the upper left, only a thin faint cyan rim light hugging the outer edge (no wide glow halo). One or two large bold shapes, very little small detail, bright overall so the silhouette reads at 24 pixels on a near-black UI. Use a signature colour only where the subject names one. Centered, fills about 85% of the canvas, transparent background. No background plate, no frame, no circle badge, no text, no letters, no numbers.
```

Генерировать пачками: в одном вызове Codex до 6 картинок, до 3 процессов параллельно (свободной памяти ≥ 3 ГБ, иначе по одному). Скрипт пакетной генерации и все промпты пакета 1 — в `assets/source/ui/icons-v2/prompts.md`.
