# Навыки проекта Asterion

Подсказки для координатора: когда упоминать навык в задании сессии.

| Навык | Когда упомянуть в задании |
|---|---|
| `asterion-game-designer` | Владелец просит идеи, или большая фича только что влилась и нужно понять, что на ней построить. Сессия предлагает 3–5 карточек, ничего не строит без «да» владельца и записывает ответы в `docs/design/IDEAS.md`. |
| `asterion-blind-ab` | Правка влияет на ключевой экран, первую минуту или ощущение боя, и нужно честно понять, стало ли лучше. Кадры «до/после» с CI, слепое сравнение скриптом `ab.cjs`, вердикт до раскрытия. Не для мелких PR. |
| `asterion-first-minute` | Задача касается главного меню, мастера новой игры или первого экрана планеты, либо владелец говорит «первое впечатление слабое». Один главный разрыв за круг, доказательство кадрами 1280×720 и 2560×1080. |

Навыки созданы по мотивам MIT-проекта studioigor-skill (https://github.com/studioigor/studioigor-skill),
переписаны под Asterion; каждый файл называет источник.

Общие правила, которые навыки не отменяют: на машине владельца тяжёлое не запускаем
(Electron, сборки, QA идут на GitHub Actions), отчёты владельцу простым русским,
белый текст на светлом арте запрещён.
