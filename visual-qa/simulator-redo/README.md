# Симулятор: снимки

- `before/` — старый экран, `after/` — новый. Размеры 1280×720 и 1920×1080.
- `after/audit.json` — автоматическая проверка каждого кадра: текст не обрезан, ячейки не наезжают друг на друга, нет сдвига вбок и лишней прокрутки страницы, нет системных списков и подсказок, центр с итогом помещается в окно. Пустой `problems` значит, что проблем нет. В `notes` записаны итоги боёв и проверка списка стрелками.
- Снимки делает `electron/simulator-redo-screenshots.cjs` (только в CI).

## Кадры

`01` пустые стороны и нет сценариев · `02` атакующий с планеты · `03` командир на каждой стороне · `04` подсказка · `05` итог, `05b` итог при прокрученных списках · `06` отчёт по раундам · `07` технологии · `08` свой список · `09`, `10` все корабли и вся оборона трёх рас · `11` огромные числа сверх лимита · `12` самые длинные числа в итоге · `13` долгий бой · `14` ничья · `15`, `16` длинное имя сценария и список со стрелками · `17`, `18` защитник из отчёта разведки и добыча.

Кадр `12` подставляет длинные строки прямо в готовый экран: настоящий бой таких чисел не даёт, потому что лимит населения 35 000.

## Почему прокручиваются списки, а не страница

Сцена игры масштабируется через `transform`, и при этом `position: sticky` уплывает. Поэтому экран целиком вписан в окно, а прокручиваются только списки сторон. Итог никуда не уходит.
