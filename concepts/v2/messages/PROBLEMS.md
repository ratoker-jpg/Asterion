# «Сообщения» сейчас: что мешает

1. Три колонки (папки, список, отчёт) — сам отчёт получает меньше половины экрана, всё мелкое.
2. Каждая строка списка — три строки текста: тип («Боевой доклад»), заголовок, превью. Тип дублирует название папки.
3. Восемь папок, половина пустует (Арена, Достижения); «Доклады» и «Командные доклады» пересекаются; шпионаж лежит в «Системе».
4. Непрочитанное видно только по крошечной точке; счётчики вида «202/203» ничего не говорят.
5. Бой: итог — маленькая плашка. Главный вопрос «выгодно ли?» не отвечен: добыча и потери не сведены в одно число.
6. Потери кораблей — длинный список карточек с уровнем мелким шрифтом, без полос «было → осталось».
7. «Кто меня ударил» — имя и координаты мелкой ссылкой, нет кнопки «ответить ударом».
8. Шпионский отчёт — длинная прокрутка ячеек «99 999 999», названия обороны рвутся на 3 строки; нет вывода «сколько унесу, хватит ли флота».
9. Кнопки разбросаны: «Удалить все» стоит рядом с «Выбрать все»; главные действия внизу мелкие.
10. Постраничность по 7 писем при 40+ сообщениях — много кликов.
11. Пустые экраны — абзацы объясняющего текста вместо картинки и одной строки.
