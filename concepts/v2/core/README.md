# Раунд 3 «Ядро» (12.11): минимальный интерфейс по принципам Frostpunk и нашей шапки

Владелец: «нравится Frostpunk, от неё сделана наша шапка, минималистичный интерфейс». Из Frostpunk берём только принципы, не рисовку:
- весь экран — это мир, интерфейс по краям;
- круги главные: в центре что-то главное, вокруг кольца, на краю маленькие круги;
- механические кольца со шкалой, как у шапки «Ядро»;
- зоны как тепло вокруг генератора;
- почти без слов.

| Экран | Файл | Идея |
|---|---|---|
| Вселенная | u-generator.html | Солнце как генератор: шкала вокруг, 8 лучей-улиц делят систему на сектора по 3 позиции, сектора с врагами подсвечены красной дугой. Слева по краю только события (атака, обломки, пираты, газ). |
| Вселенная | u-wheel.html | Колесо галактики: 40 систем по кругу (обломки и враги отмечены дугой снаружи), текущая система внизу, внутри колеса её 24 позиции на двух кольцах. |
| Рейсы | f-clock.html | Часы на 4 часа вперёд: сверху «сейчас», по часовой позже. Внешнее кольцо — ваши флоты, внутреннее красное — то, что летит на вас. В центре ближайший удар. |
| Рейсы | f-hubs.html | Каждая ваша планета — круг как в шапке, её флоты на кольце по ходу полёта. Атаки ждут снаружи кольца, красные. Снизу одна полоса выбранного рейса. |
| Сообщения | m-journal.html | Одна страница-отчёт в центре: медальон боя, одно слово итога, одна строка, три числа, три кружка действий. Письма кружками по дням у левого края. |
| Сообщения | m-ring.html | Сутки как циферблат: письма стоят на своём часе, непрочитанные ярче. В центре открытый бой, справа потери полосами. |
